## Cara Menjalankan Secara lokal

1. Clone repository dengan menyalin url repo
2. jalankan `npm install` untuk mengunduh dependencies yang dibutuhkan.
3. jalankan `npm run dev` untuk menampilkan link localhost.
4. Salin localhost dan tempel pada mesin pencari.
